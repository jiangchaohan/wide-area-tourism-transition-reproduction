# Existing-data strengthening protocol

Prepared on 2026-10-04 before inspecting new experiment outcomes. The original submission and data remain unchanged. New analyses are additional/post-hoc to the original study, not prospectively registered research.

1. Preserve the 70/15/15 complete-route split for comparison, but evaluate fixed-date, strictly disjoint rolling splits as sensitivity analyses. Count overlap at both event and unique-fragment levels and separate route-start events from order-two contexts.
2. Compare unweighted/weighted first order and unweighted/weighted variable order. Select context support on validation only from 1,2,3,5,10,20,50,100. Report paired route-cluster and template-cluster intervals for TD-VOM versus VOM as well as first order. Do not claim that repetition is erroneous tourist demand.
3. Add an interpolated order-two baseline with strength 1,5,10,20,50,100 chosen on validation, and validation-selected rank-16/32/64/128 log-transition factorization. Fix deterministic ties by score, training popularity, then state identifier; compare against original archive tie behavior.
4. Stratify by seen/unseen context and edge, training target frequency, route length and geographic separation. Report subgroup sample sizes and template-balanced evaluation. These are historical product diagnostics, not field evidence of management effects.
5. Evaluate attraction-identity uncertainty using already flagged records and supplied entity-review entries. Never silently merge spatially nearby or parent-child attractions. Excluding flagged records is a sensitivity analysis with a different sample, not a redefinition of the original dataset.
6. Neural comparators are local GRU and causal-transformer implementations inspired by GRU4Rec/SASRec, not official implementations. Use full-catalog next-item cross-entropy, validation-only hyperparameter selection, maximum 30 epochs, patience 5 and three final seeds (2026,2027,2028). Select among learning rates 0.001 and 0.0003 at dimension64, maximum prefix40. Save histories, checkpoints and event-level predictions. Test is not used for hyperparameter choice. If unavailable runtime/resources prevent completion, disclose incomplete trials rather than substitute archived single-seed results.
7. Keep all outcome directions, including evidence against weighting or neural superiority. Revise manuscript claims only after results exist. No new interviews, surveys, tourist movements, causal effects or road-network evidence will be fabricated.
